# Pink Beauty Clinic & Salon — Website Bundle

A no-build static website using plain HTML, CSS and JavaScript.

## Structure

- `index.html` — page structure + SEO metadata
- `style.css` — responsive design, animations and components
- `script.js` — menu, service filters, image lightbox and WhatsApp enquiry
- `logo.svg` — crisp vector wordmark/crown treatment
- `images/gallery/` — 15 renamed real salon/clinic media files
- `images/reviews/` — 26 renamed guest review screenshots
- `site.webmanifest`, `robots.txt` — deployment/SEO helpers

## Local preview

Run from this folder:

```bash
python -m http.server 8080
```

Then open:
`http://localhost:8080`

## Deployment

Upload the contents of this folder to GitHub Pages, Vercel, Netlify or any static host.

No npm install is required.

## Before publishing

- Confirm current services, hours and pricing with the salon.
- Confirm the lash campaign offer is still active before keeping the supplied promo artwork as an active offer.
- Add the salon's Instagram/official social URL if desired.

## Notes

The site deliberately avoids hard-coded pricing and opening hours because the supplied materials and external listings do not establish one unambiguous current schedule.
